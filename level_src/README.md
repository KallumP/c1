# Maps

Maps modelled in Blender, for making [custom levels](../doc/custom_levels.md) with `python tools/generate_level_terrain.py maps/<map>`. Each map is a folder holding its `.obj`, `.mtl` and images, and a `map.cfg` with its `turn` and `scale` if they aren't the defaults.

One map is included in the repository: `tide_ruins/`, made for c1x. Make its level with `python tools/generate_level_terrain.py maps/tide_ruins` and boot into it with `boot_level = tide_ruins` in `settings.cfg`. The rest of `maps/` is ignored by git, so maps you add stay local.

| Map | Make it with | Source |
|---|---|---|
| `tide_ruins/` | `python maps/tide_ruins/build_tide_ruins.py`, then `python tools/generate_level_terrain.py maps/tide_ruins` | Made for c1x: generated by `build_tide_ruins.py` from a grid drawn in the script, with procedural textures. |
