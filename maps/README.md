# Maps

Maps modelled in Blender, exported as `.obj`, for making [custom levels](../doc/custom_levels.md) with `python tools/nslevel.py map`.

| Map | Make it with | Source |
|---|---|---|
| `simple_afps_level.obj` | `python tools/nslevel.py map maps/simple_afps_level.obj --turn 90` | [Simple AFPS Level](https://opengameart.org/content/simple-afps-level) by drummyfish, [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Changed: an object named `spawn` added on the main floor at the start of the right hand side, and the `mtllib` line removed (its materials and textures aren't used). |
